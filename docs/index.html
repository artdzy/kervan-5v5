00 — Overview

A complete competitive shooter built from scratch for the web: authoritative server, lag-compensated hit detection, bots with path-finding, and a custom post-processing pipeline written directly in GLSL.

One team plants the bomb. The other holds the site. Rounds, money, utility and nerve — the rhythm of a tactical shooter, running in a browser tab you can share with a single link.

A / Objective

Plant & defuse

Hold E for 3.2 s to plant on site A or B. Defuse takes 10 s, or 5 s with a kit.

B / Economy

Buy every round

Per-weapon kill rewards. Buy in spawn during the first 20 seconds of the round.

C / Bots

They play the map

Bots buy, rotate through A, B and the tunnel with A* path-finding, plant and defuse.

D / Netcode

Lag compensated

Server-side rewind for hit detection, client prediction and interpolated remote players.

04

Rendering

No off-the-shelf effects. Every post-processing pass is hand-written GLSL, tuned for a cinematic look and scaled through Ultra, High and Low presets with an automatic pixel budget on high-DPI screens.

HDR scene

MSAA, depth texture, PBR materials and HDRI image-based lighting.

SSAO

Half-resolution ambient occlusion that fades out on sunlit surfaces.

Volumetrics

Ray-marched sun shafts through the shadow map, two-lobe phase function.

Wet world

Planar reflections, puddle masks, ripple rings, GPU rain and splashes.

Bloom & lens

Six-level bloom, eye adaptation, lens dirt, ghosts and starburst flare.

Final grade

ACES/AgX tone mapping, split-tone grade, vignette, film grain, dither.

06

Play it

Requires Node.js 18 or newer on the host. Players only need a browser.

A / Local network

Start a server

Run the server and open it in your browser. Friends on the same network join via the LAN address it prints.

$ git clone https://github.com/artdzy/kervan-5v5.git
$ cd kervan-5v5
$ npm install
$ npm start

Then open http://localhost:3000

B / Over the internet

Share one link

Expose the game for free with a Cloudflare Quick Tunnel — no account, no port forwarding.

$ brew install cloudflared  # once
$ npm start                 # terminal 1
$ npm run tunnel            # terminal 2

Send the https://….trycloudflare.com address to your squad.
